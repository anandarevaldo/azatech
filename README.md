# Azatech Online Shop

Technical test Medior Fullstack Developer - Track A.

## Struktur proyek

```text
.
├── backend/    # REST API dan logika bisnis
├── frontend/   # Aplikasi web admin
└── README.md
```

## Rencana teknologi

- Backend: Node.js 24+, NestJS, TypeScript strict, Prisma ORM, PostgreSQL.
- Autentikasi: JWT access token dan refresh token.
- Validasi dan testing: NestJS validation, Jest, dan Supertest.
- Frontend: React 19, Next.js App Router, TypeScript, dan TanStack Query.

## Urutan pengerjaan

1. Menyiapkan struktur dan konfigurasi dasar proyek.
2. Membuat database schema, migration, dan seed.
3. Membuat autentikasi.
4. Membuat produk dan pelanggan.
5. Membuat order dengan transaksi database dan validasi stok.
6. Membuat dashboard, dokumentasi API, dan automated test.
7. Membuat halaman frontend satu per satu.

## Catatan

Implementasi akan dibuat bertahap agar setiap bagian mudah dipahami dan diuji.
